# 🌐 My Personal Portfolio Website

Welcome to my personal portfolio project! This website showcases my skills, Education, projects, and contact information as a frontend developer.

👉 **[Live Demo Link](https://github.com/ushasri2005/MyPortfolio)**


## 🚀 Features
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
* **Interactive Elements:** Dynamic project filtering and smooth animations using JavaScript.
* **Contact Form:** An easy way for recruiters and clients to get in touch with me.

## 🛠️ Tech Stack Used
* **HTML5:** Structured the semantic web pages.
* **CSS3:** Styled the layout using Flexbox/Grid and custom animations.
* **JavaScript (ES6):** Added interactivity and dynamic functions.
